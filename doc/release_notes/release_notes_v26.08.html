Fraxinus release notes

v26.08

Changes since v22.09

New Features

KeySummaryRelease Note
Fraxinus#42Make self-extracting Fraxinus Ubuntu installerAdded a single-file Ubuntu installer script that downloads and sets up Fraxinus automatically.
Fraxinus#41Update public documentationUpdated the public Fraxinus website with current workflow description and screenshots.
Fraxinus#40Fraxinus public versionFraxinus is now available as an open-source public version, with tracking-related code moved to a separate private component.
Fraxinus#37Layout option in Fraxinus VBAdded a virtual bronchoscopy layout option with larger VB + ACS + 3D views, and made the screenshot/video toolbar visible by default.
Fraxinus#26EBUS simulator add abdominal viewAdded an abdominal 2D view to the EBUS simulator, to help identify lymph nodes in CT.
Fraxinus#13MDT widgetAdded an MDT (multidisciplinary team meeting) widget and workflow, showing clinical variables and object colors read from a CSV file.
Fraxinus#21Improve data import flow and info in FraxinusAdded informational dialogs when a patient is created, data is imported, and segmentation is completed, to make the import flow clearer.
Fraxinus#39Improvements in FraxinusVarious Fraxinus usability improvements: square virtual bronchoscopy view, full centerline tree shown in VB, automatic CT/PET modality assignment on import, and a streamlined patient loading and segmentation workflow with inline progress.
Fraxinus#38Make simpler virtual camera rotationSimplified automatic camera rotation in virtual bronchoscopy, based on the target's lobe location.
Fraxinus#34Simpler CT import in FraxinusSimplified the CT import and patient creation flow in Fraxinus with a streamlined dialog.
Fraxinus#35Make Fraxinus segmentations run on WindowsRaidionics and TotalSegmentator segmentation now also work on Windows.
Fraxinus#32Compile Fraxinus on WindowsFraxinus can now be built and installed on Windows.
Fraxinus#24Smoothing of meshes in FraxinusAdded configurable smoothing of segmented structure meshes, for smoother-looking and smaller models.
Fraxinus#20Integrate TotalSegmentatorIntegrated TotalSegmentator for segmenting lung blood vessels and lung lobes.
Fraxinus#19Interactive tumor assessmentAdded interactive review of segmented tumors and lung nodules: each detected lesion can be confirmed or rejected individually.
Fraxinus#18New tumor segmentation with RaidionicsReplaced the previous tumor segmentation (LungTumorMask) with a new AI model running in Raidionics.
Fraxinus#12EBUS simulatorAdded an EBUS (endobronchial ultrasound) simulator, showing a simulated ultrasound sector from CT during virtual bronchoscopy.
Fraxinus#8Fraxinus fixesSeveral virtual bronchoscopy improvements: show target and via points during navigation, display segmented structures in 2D view (previously 3D only), and switch to the post-processed airway model for smoother visualization.
Fraxinus#7Navigate VB with keysAdded keyboard shortcuts to navigate and control virtual bronchoscopy, including up/down angle adjustment.

20 issues

Bugfixes

KeySummaryRelease Note
Fraxinus#27Downsample CT image to 512x512Fixed AI segmentation failures on high-resolution (1024x1024) CT images by automatically downsampling to 512x512 before segmentation.
Fraxinus#36Centerline generation in separate threadFixed the application freezing for about a minute during airway centerline generation, by moving the processing to a background thread.
Fraxinus#33Udate raidionicsUpdated to a newer Raidionics AI segmentation version and fixed related batch-size and segmentation-order issues.
Fraxinus#25Correct export of centerlinesFixed an incorrect coordinate system on exported airway centerlines, which caused misalignment when importing Fraxinus data into other systems.
Fraxinus#23Use nodule segmentation from TotalSegmentator in FraxinusReplaced the previous lung-nodule segmentation method with TotalSegmentator, removing a dependency-troubled component.
Fraxinus#16Limit automatic bronchoscope rotationLimited automatic bronchoscope camera rotation to the first airway generations, since rotation further out was more distracting than helpful.
Fraxinus#6Disable center to tool in 2DDisabled "center to tool" in 2D views for the Pinpoint and Procedure Planning workflows, since it caused 2D slices to jump distractingly when selecting a new position.
Fraxinus#5PET elastix registration failsFixed a mismatch between CT and PET-CT after PET/Elastix registration by tuning registration parameters.
Fraxinus#3Fix bug in LungTumorMaskFixed a GPU-related failure in lung tumor segmentation (LungTumorMask) by forcing it to run on CPU.
CustusX#20GenericScriptFilter issuesFixed script configuration file path handling for GenericScriptFilter in CustusS and Fraxinus.
